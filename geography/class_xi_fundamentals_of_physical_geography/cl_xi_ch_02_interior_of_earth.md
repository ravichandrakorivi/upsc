<strong>A.</strong> Crust → Asthenosphere → Mantle → Outer core → Inner core<br>
<strong>B.</strong> Crust → Lithosphere → Mantle → Outer core → Inner core<br>
<strong>C.</strong> Lithosphere → Crust → Outer core → Mantle → Inner core<br>
<strong>D.</strong> Crust → Mantle → Lithosphere → Outer core → Inner core

</div>

<br>

**Answer**: **B**

> **Explanation:** The crust forms the outermost layer, the mantle lies below it, followed by the outer and inner core. The lithosphere is a mechanical combination of the crust and uppermost mantle rather than a separate compositional layer.
